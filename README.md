# 🦷 Happy Dental Hub – Dental Appointment Booking App

Happy Dental Hub is a dental appointment booking application that lets patients easily schedule dental visits online, without waiting in queues or making phone calls. It was developed as a team project for **FSD 2 (Full Stack Development 2)** by a team of four.

## ✨ Features
- Patient registration and login
- Browse available dentists and services
- Book, view, and cancel appointments
- Admin panel to manage appointments, doctors, and patients
- Data stored securely in a database

## 🛠️ Tech Stack
- **IDE:** Eclipse
- **Backend:** Java (Servlets)
- **Frontend:** HTML, CSS, JavaScript
- **Database:** Oracle
- **Server:** Apache Tomcat
